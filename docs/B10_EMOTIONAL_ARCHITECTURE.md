# B10 — ЭМОЦИОНАЛЬНАЯ АРХИТЕКТУРА

Дата: 23.09.2026

Эмоциональная дуга романа строится вокруг постепенного изменения способности Алексея чувствовать, выбирать и действовать, а не вокруг набора искусственных драматических ударов.

## Этапы

1. Эмоциональное онемение — функциональность вместо участия.
2. Любопытство — письмо нарушает привычную систему.
3. Привязанность — появляются реальные человеческие связи.
4. Тревога — найденная информация начинает касаться прошлого героя.
5. Надежда — появляется возможность изменить отношения.
6. Ошибка — Алексей делает выбор и недооценивает последствия.
7. Потеря — цена выбора становится личной.
8. Разрыв старой стратегии — молчание больше не воспринимается безопасным выходом.
9. Выбор — герой действует без гарантии нужного результата.
10. Принятие — ответственность отделяется от самонаказания.
11. Тихая новая жизнь — изменение проявляется в конкретных действиях.

## Эмоциональный ритм

Напряжение → движение → человеческая сцена → открытие → последствие → передышка → новое напряжение.

Передышка должна тоже менять персонажа или ситуацию.

## Крупные эмоциональные узлы

1. Обнаружение письма.
2. Осознание личной связи с темой письма.
3. Последствия спорного решения.
4. Финальный поступок без гарантии прощения.

## Главные отношения

София проверяет способность Алексея говорить до полной уверенности.

Дмитрий проверяет его способность признавать семейную ответственность.

Елена показывает, что честное признание не даёт права требовать возврата прошлого.

Андрей показывает цену отложенного ответа, но не даёт готовой философии.

Лука раскрывает тему позднего сожаления.

## Правила эмоциональной честности

Не писать эмоцию вместо сцены. Сначала показывать тело, действие, реакцию, избегание, диалог и конкретную деталь; затем при необходимости давать осмысление.

Запрещены дешёвые эмоциональные манипуляции: внезапные смерти ради слёз, чудесные примирения, неестественно мудрые реплики и постоянные катастрофы.

## Целевой читательский эффект

Узнавание → любопытство → привязанность → тревога → надежда → сомнение → удар → понимание → выбор → тихое послевкусие.
