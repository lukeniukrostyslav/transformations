# TRANSFORMATIONS — ФИЛЬТР ФОРМАТИРОВАНИЯ ПРОЗЫ

Дата: 23.09.2026

## Цель

Исключить визуальный эффект «лесенки», когда художественная проза разбивается на множество строк по 1–3–4 слова. Роман должен выглядеть как профессиональная цельная проза.

## Правила

1. Обычный повествовательный абзац содержит несколько связанных предложений; ориентир — не менее 25 слов.
2. Не использовать отдельные абзацы из 1–3–4 слов для обычного повествования.
3. Короткие реплики допустимы внутри естественного диалога, но не должны превращать сцену в чередование однофразовых строк.
4. Короткие предложения объединяются с соседним абзацем, если отдельная строка не нужна для ритма.
5. Не разбивать одно смысловое действие на несколько визуальных строк ради эффектности.
6. Каждый абзац должен быть полноценной смысловой единицей.
7. Ориентир основной прозы — 2–6 предложений в абзаце.
8. Сценические разделители сохраняются только при реальной смене места, времени или эмоционального режима.
9. Перед коммитом проверять word count, длину абзацев и визуальную «лесенку».
10. После каждой главы повторно выполнять Paragraph Format Gate.

## Paragraph Format Gate

PASS только если короткие абзацы отсутствуют в обычной повествательной прозе или имеют явное художественное основание.

Фильтр обязателен для B19 и повторной проверки на B20–B24.
